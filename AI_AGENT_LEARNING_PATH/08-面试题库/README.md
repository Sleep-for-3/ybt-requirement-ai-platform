## 使用方法

不要逐字背“高级回答”。先用 90 秒回答，再看四点是否齐全：

1. 定义准确。
2. 有工程作用。
3. 有一表通项目落点。
4. 有权衡、失败或评测。

每周抽 30 题：

- 20 题限时 90 秒。
- 5 题追问 3 层。
- 5 题画图或指源码。

错题标记：

- A：概念不会。
- B：会概念但说不出项目。
- C：有项目但没有指标/权衡。
- D：把计划说成已实现。
