# 工程 50 题

## 1. FastAPI 为什么适合 AI 应用？
**答案：** Python生态、类型校验、异步 I/O和自动 OpenAPI。  
**追问：** 主要风险？  
**高级回答：** 不能把阻塞解析/同步数据库滥塞进 event loop，也不能把业务逻辑全写在路由。

## 2. async/await 解决什么？
**答案：** 在等待网络/I/O时让事件循环处理其他任务。  
**追问：** 能加速 CPU 任务吗？  
**高级回答：** 不能直接；PDF/OCR/大表解析应进线程、进程或 Celery。

## 3. I/O-bound 与 CPU-bound 区别？
**答案：** 前者主要等待外部资源，后者主要消耗计算。  
**追问：** LLM 调用属于哪类？  
**高级回答：** HTTP等待是 I/O-bound；本地模型推理/复杂 rerank是计算型，需专用服务/资源。

## 4. 如何限制并发 LLM 调用？
**答案：** semaphore、连接池、队列和按项目配额。  
**追问：** 只靠 provider限流行吗？  
**高级回答：** 会产生429和重试风暴；应用应前置背压并监控排队时间。

## 5. FastAPI Depends 有什么价值？
**答案：** 声明式注入数据库、认证、权限等请求依赖。  
**追问：** 项目如何使用？  
**高级回答：** Principal与DB Session进入权限服务，resource guard再按路径资源归属授权。

## 6. Middleware 适合做什么？
**答案：** 横切请求处理，如 request id、日志、限流和安全头。  
**追问：** 适合业务权限吗？  
**高级回答：** 可做统一入口，但复杂资源授权仍应由可测试的 PermissionService/依赖完成。

## 7. Pydantic 的作用？
**答案：** 基于类型做验证、序列化和 JSON Schema。  
**追问：** AI 输出为什么要验证？  
**高级回答：** 模型是不可信边界，必须 extra=forbid、枚举、长度和业务二次校验。

## 8. `model_validate` 与 `model_dump`？
**答案：** 前者把输入验证成模型，后者序列化模型。  
**追问：** 缺字段怎么办？  
**高级回答：** 对必填业务字段抛 ValidationError，记录失败并有限重试/转人工，不静默补假默认值。

## 9. Python ABC 与 Protocol 区别？
**答案：** ABC偏显式继承与运行时约束，Protocol偏结构化类型。  
**追问：** LLMService为什么用ABC？  
**高级回答：** 明确 provider必须实现 chat/embed；若要第三方无继承适配可考虑Protocol。

## 10. 组合优于继承何时成立？
**答案：** 多个独立能力应注入组合，避免脆弱类层次。  
**追问：** 项目例子？  
**高级回答：** GenerationPipeline组合 Retriever、LLM、Validator、Logger，而非继承巨型 BaseAgent。

## 11. SQLAlchemy Session 是什么？
**答案：** ORM对象状态与数据库事务交互的工作单元。  
**追问：** 可跨线程共享吗？  
**高级回答：** 不可并发共享；请求/任务拥有独立 Session并明确关闭。

## 12. flush 与 commit 区别？
**答案：** flush把变更发到当前事务，commit提交并持久化。  
**追问：** 为什么先 flush？  
**高级回答：** 获取生成ID并继续写关联记录，同时仍可整体 rollback。

## 13. rollback 后 Session 要注意什么？
**答案：** 回滚事务并处理对象状态，继续使用前确认 Session可用。  
**追问：** API异常如何做？  
**高级回答：** 在统一会话边界rollback/close，避免半提交和脏状态泄漏到后续请求。

## 14. 什么是 N+1？
**答案：** 查询列表后为每项额外发一次关联查询。  
**追问：** 如何解决？  
**高级回答：** join/selectinload、批量ID查询，并用SQL日志/性能测试验证。

## 15. 乐观锁是什么？
**答案：** 更新时校验版本号，冲突则拒绝而非锁住记录。  
**追问：** AI草稿场景？  
**高级回答：** Agent保存时带 expected_version，若人工已编辑则不覆盖并创建冲突。

## 16. 数据库事务隔离解决什么？
**答案：** 控制并发事务之间可见性和异常。  
**追问：** 隔离越高越好吗？  
**高级回答：** 更高隔离增加冲突/成本，应按审核状态、任务幂等和一致性需求选择。

## 17. 如何设计索引？
**答案：** 根据真实查询过滤、排序和选择性设计。  
**追问：** 项目例子？  
**高级回答：** KnowledgeUnit按scope/project/enabled/type，AuditLog按institution/project/action/time建复合索引并用EXPLAIN验证。

## 18. JSONB 适合什么？
**答案：** 半结构化扩展字段和配置，支持索引查询。  
**追问：** 什么不该放？  
**高级回答：** 频繁关联、强约束的核心字段应规范化，不能把所有业务模型塞进一个JSON。

## 19. PostgreSQL RLS 是什么？
**答案：** 数据库按策略限制用户可见/可改行。  
**追问：** 能替代应用权限吗？  
**高级回答：** 不能，作为纵深防御；连接上下文、owner绕过和策略测试都要治理。

## 20. Alembic 的作用？
**答案：** 版本化管理数据库 Schema 迁移。  
**追问：** 生产迁移注意什么？  
**高级回答：** 前后兼容、备份、锁表影响、回滚/roll-forward和应用发布顺序。

## 21. Redis 在项目中做什么？
**答案：** 主要作为 Celery broker/result backend，也可做受控缓存。  
**追问：** 能存最终审核状态吗？  
**高级回答：** 不作为唯一事实源，最终状态在PostgreSQL事务中。

## 22. 缓存穿透是什么？
**答案：** 大量查询不存在键，反复打到后端。  
**追问：** 如何处理？  
**高级回答：** 参数校验、短TTL负缓存、限流；多租户缓存key必须带scope。

## 23. 缓存击穿是什么？
**答案：** 热点键失效时大量请求同时回源。  
**追问：** 怎么防？  
**高级回答：** single-flight/互斥重建、TTL抖动和提前刷新。

## 24. Celery 的基本组件？
**答案：** producer、broker、worker、task和result backend。  
**追问：** 为什么适合AI任务？  
**高级回答：** 摄取、评测和Agent多步耗时，可异步、重试、跟踪进度和取消。

## 25. Celery 是 exactly-once 吗？
**答案：** 通常是 at-least-once，可能重复执行。  
**追问：** 怎么保证业务正确？  
**高级回答：** idempotency key、唯一约束、状态机和事务，而非依赖 task id。

## 26. 什么是 acks_late？
**答案：** 任务执行后再确认消息，Worker崩溃可重投。  
**追问：** 风险？  
**高级回答：** 可能重复执行，所以只适合幂等任务并需可观测重试。

## 27. Celery 重试怎么设计？
**答案：** 仅临时错误，指数退避、抖动、上限和告警。  
**追问：** Schema错误重试吗？  
**高级回答：** 原输入不变通常无意义，应记录并转人工/修数据。

## 28. 后台任务如何报告进度？
**答案：** 持久化 job/item状态、当前步骤和汇总。  
**追问：** 只看Celery状态够吗？  
**高级回答：** 不够；业务需 BackgroundJob 支持部分成功、审计、取消和恢复。

## 29. Docker镜像与容器区别？
**答案：** 镜像是只读模板，容器是其运行实例。  
**追问：** 密钥放镜像吗？  
**高级回答：** 不放；通过运行环境/secret注入，日志和构建缓存也不得泄漏。

## 30. Docker Compose 的价值？
**答案：** 用YAML定义和运行多容器应用。  
**追问：** 等于生产编排吗？  
**高级回答：** 适合开发/小规模部署，生产还需高可用、secret、备份、监控和容量方案。

## 31. Healthcheck 分哪两类？
**答案：** liveness看进程活着，readiness看能否接流量。  
**追问：** 外部模型故障影响哪个？  
**高级回答：** 本地服务仍可live，但关键依赖不可用时ready或能力状态应反映降级策略。

## 32. 如何做配置管理？
**答案：** 环境变量+类型化Settings，分环境验证，secret外置。  
**追问：** 默认值越多越好吗？  
**高级回答：** 开发可有安全默认，生产关键密钥/认证/CORS必须启动时强校验。

## 33. 什么是连接池？
**答案：** 复用数据库/HTTP连接降低建立成本。  
**追问：** 池越大越好吗？  
**高级回答：** 会压垮数据库/provider；按并发、超时和后端容量设置并监控等待。

## 34. HTTP超时如何拆分？
**答案：** connect、read、write、pool和总任务超时。  
**追问：** 只设60秒够吗？  
**高级回答：** 不够精细；错误分类、重试和SLO需要知道卡在哪一阶段。

## 35. 什么是熔断？
**答案：** 依赖持续失败时暂时阻断调用，避免级联故障。  
**追问：** RAG怎么降级？  
**高级回答：** 向量库故障可降级关键词；LLM故障返回证据列表/待确认，不能伪造答案。

## 36. 什么是背压？
**答案：** 下游处理不过来时限制/延缓上游输入。  
**追问：** AI平台例子？  
**高级回答：** 限制并发模型调用、队列长度和每项目任务，超额明确拒绝或排队。

## 37. 什么是结构化日志？
**答案：** 用固定字段记录机器可查询事件。  
**追问：** 项目关键字段？  
**高级回答：** request/trace/correlation、user/institution/project、route、job、model/retrieval和duration，内容需脱敏。

## 38. Metrics、Logs、Traces区别？
**答案：** 指标看趋势，日志看事件，Trace看跨组件链路。  
**追问：** AI质量放哪？  
**高级回答：** Recall/citation/拒答是业务质量指标，具体失败通过RetrievalLog/ModelCallLog和trace定位。

## 39. 如何设计 request id？
**答案：** 入口生成/接受合法ID并贯穿响应和日志。  
**追问：** 后台任务呢？  
**高级回答：** 另有correlation/trace id关联原请求，不能把线程局部状态直接假设会跨进程。

## 40. API限流按什么维度？
**答案：** IP、用户、机构、项目、endpoint和成本权重。  
**追问：** 只按IP问题？  
**高级回答：** 代理/NAT下不公平，也不能控制高成本模型任务；需认证维度和配额。

## 41. 如何保护敏感日志？
**答案：** 字段白名单、脱敏、摘要/哈希、访问控制和保留期限。  
**追问：** 异常堆栈呢？  
**高级回答：** 也可能含SQL参数、URL密钥和Prompt，必须统一过滤。

## 42. Git小步提交的价值？
**答案：** 易审查、定位、回滚和bisect。  
**追问：** AI配置也要版本吗？  
**高级回答：** 要；Prompt、模型、检索配置和数据集版本决定行为。

## 43. CI 应跑什么？
**答案：** lint/type、单测、集成、迁移、构建和安全检查。  
**追问：** AI质量怎么进CI？  
**高级回答：** 小型确定性/Mock集每次跑，真实模型黄金集按发布或定时跑并设门禁。

## 44. 单元测试与集成测试区别？
**答案：** 单测隔离组件，集成测真实组件协作。  
**追问：** RAG需要哪种？  
**高级回答：** tokenizer/融合用单测，摄取→检索→citation用集成，真实模型另做离线评测。

## 45. 如何测试异步代码？
**答案：** 使用异步测试框架、mock I/O、超时和取消路径。  
**追问：** 只测成功够吗？  
**高级回答：** 要测429、超时、截断、Schema失败、取消和重复提交。

## 46. 什么是 Smoke Test？
**答案：** 快速验证关键端到端功能可用。  
**追问：** 项目覆盖什么？  
**高级回答：** 文档/Excel/SQL摄取、检索引用、拒答、目录探查、映射、敏感保护和导出。

## 47. 如何做数据库备份恢复？
**答案：** 定期全量/增量、加密、异地并实际演练恢复。  
**追问：** 向量库呢？  
**高级回答：** 可备份但也要能从事实库重建，记录embedding版本和一致性检查。

## 48. 如何处理零停机 Schema 变更？
**答案：** expand-migrate-contract，先兼容新增，再回填和切换，最后删除。  
**追问：** Prompt Schema呢？  
**高级回答：** 同样需版本兼容，消费者先支持新旧，再切Prompt输出。

## 49. 如何做性能基线？
**答案：** 固定环境、数据和负载，记录吞吐、P50/P95、错误和资源。  
**追问：** AI还要记录什么？  
**高级回答：** Token、模型/embedding版本、Top-K、缓存命中和质量指标，避免只优化延迟损失正确率。

## 50. 你如何排查一次RAG接口变慢？
**答案：** 沿trace拆解析、DB、关键词、向量、rerank、LLM和序列化耗时。  
**追问：** 第一反应扩容吗？  
**高级回答：** 先用证据定位；可能是索引缺失、Top-K膨胀、连接池等待、provider限流或重试风暴。
