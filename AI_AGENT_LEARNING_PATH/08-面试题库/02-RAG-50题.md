# RAG 50 题

## 1. 什么是 RAG？
**答案：** 先检索外部证据，再让生成模型基于证据回答。  
**追问：** 核心价值只是降幻觉吗？  
**高级回答：** 还包括知识可更新、权限可过滤和答案可引用；一表通平台更看重治理和追溯。

## 2. RAG 与搜索有什么区别？
**答案：** 搜索返回文档，RAG 在检索结果上生成任务答案。  
**追问：** 风险多在哪里？  
**高级回答：** 多了生成误读和引用错配，因此要分别评检索与生成，不能只看最终文本。

## 3. RAG 与微调如何选择？
**答案：** 动态事实和引用用 RAG，行为模式和风格可考虑微调。  
**追问：** 能组合吗？  
**高级回答：** 可以，微调领域分类/表达，RAG提供最新证据，但两者都要独立评测。

## 4. RAG 的基本链路？
**答案：** 解析、Chunk、索引、检索、排序、上下文构建、生成、引用、评测。  
**追问：** 哪一步最重要？  
**高级回答：** 没有单点答案；先用分层指标找到瓶颈，一表通常见短板是结构解析、精确字段召回和证据时效。

## 5. 文档解析为什么重要？
**答案：** 垃圾解析会让后续检索和引用全部失真。  
**追问：** Excel 的难点？  
**高级回答：** 多层表头、合并单元格、横向场景、公式和值，还要保留 sheet/cell 定位。

## 6. 扫描 PDF 怎么处理？
**答案：** OCR、版面分析、页码映射和人工抽检。  
**追问：** OCR 文本能直接入库吗？  
**高级回答：** 需记录置信度、原图定位和低置信片段；关键金额/字段应转人工确认。

## 7. 什么是 Chunk？
**答案：** 检索和引用的最小知识片段。  
**追问：** Chunk 越小越好吗？  
**高级回答：** 过小丢限定条件，过大引入噪声；按问答、字段场景、标题和 SQL 逻辑结构切分更合适。

## 8. Chunk overlap 有什么用？
**答案：** 保留跨边界上下文，降低信息被切断。  
**追问：** 重叠越多越好吗？  
**高级回答：** 会增加重复召回、索引和 Token；应通过黄金集测量，不固定迷信百分比。

## 9. 结构化 Chunk 与固定长度 Chunk 区别？
**答案：** 前者按文档语义单元切，后者按字符/Token 数切。  
**追问：** 一表通选哪个？  
**高级回答：** 优先字段+场景+口径等结构化单元，超长时再在单元内二次切分。

## 10. Chunk 应保存哪些元数据？
**答案：** 来源、定位、版本、范围、类型、场景、时间和敏感等级。  
**追问：** 元数据只用于展示吗？  
**高级回答：** 还用于检索前权限/适用性过滤、排序和 citation 校验。

## 11. 什么是稀疏检索？
**答案：** 基于词项匹配的检索，如 BM25。  
**追问：** 优势？  
**高级回答：** 对字段代码、制度号、表名和罕见术语精确，且可解释。

## 12. BM25 的直觉？
**答案：** 词频有饱和、稀有词权重高，并对文档长度归一化。  
**追问：** 项目当前是 BM25 吗？  
**高级回答：** 当前是加权 Token 倒排与规则得分，不能包装成完整 BM25；生产可引入 FTS/OpenSearch 后实测。

## 13. 什么是稠密检索？
**答案：** 用 query/document embedding 相似度召回语义相近文本。  
**追问：** 弱点？  
**高级回答：** 精确 ID、数字、否定、时间和权限需额外机制。

## 14. cosine similarity 是什么？
**答案：** 比较向量方向相似度，常用于归一化 embedding。  
**追问：** 分数 0.8 一定相关吗？  
**高级回答：** 不同模型/语料不可直接套阈值，必须用标注集校准。

## 15. 向量维度越高越好吗？
**答案：** 不一定，会增加存储和计算，质量取决于模型训练。  
**追问：** 如何选？  
**高级回答：** 在领域集上比较 Recall、延迟、索引大小和成本。

## 16. 什么是向量数据库？
**答案：** 存储向量和元数据并提供近似最近邻搜索的系统。  
**追问：** 能替代 PostgreSQL 吗？  
**高级回答：** 不能；PostgreSQL 保存事实、权限和事务，向量索引应可重建。

## 17. ANN 为什么是近似搜索？
**答案：** 用索引牺牲少量召回换取大规模查询速度。  
**追问：** 如何调参？  
**高级回答：** 同时观察 Recall@K、P95 延迟、内存和构建时间，不能只追速度。

## 18. embedding 模型升级怎么办？
**答案：** 新旧向量空间不兼容，需重建索引。  
**追问：** 如何不停机？  
**高级回答：** 双索引后台重建、回放评测、切换读别名并保留回滚。

## 19. 什么是 Hybrid Search？
**答案：** 组合稀疏、稠密和结构化/业务信号。  
**追问：** 为什么适合银行？  
**高级回答：** 同时处理自然语言同义词、精确字段代码、场景权限和权威版本。

## 20. score fusion 的问题？
**答案：** 不同检索器分数尺度可能不可比。  
**追问：** 怎么解决？  
**高级回答：** 校准归一化或用 RRF 等 rank fusion，再以黄金集验证。

## 21. 什么是 RRF？
**答案：** 按各列表中的排名倒数融合，不依赖原始分数尺度。  
**追问：** 一定优于加权分数吗？  
**高级回答：** 不一定；它稳健但忽略分数幅度，需在字段代码和自然语言切片上对比。

## 22. 什么是 Rerank？
**答案：** 对初召回候选进行更精细的二阶段排序。  
**追问：** 为什么不直接 rerank 全库？  
**高级回答：** cross-encoder 成本高，先高召回候选再精排可平衡质量和延迟。

## 23. bi-encoder 与 cross-encoder 区别？
**答案：** 前者分开编码适合召回，后者联合编码适合精排。  
**追问：** 项目当前有 cross-encoder 吗？  
**高级回答：** 没有；当前是规则融合得分，下一步需作为独立实验而非改名包装。

## 24. Query Rewriting 有什么用？
**答案：** 把用户问题改写为更适合检索的查询。  
**追问：** 风险？  
**高级回答：** 可能改错字段或范围；应保留原查询、多查询融合并记录 rewrite trace。

## 25. Multi-query Retrieval 是什么？
**答案：** 生成多个不同角度查询并合并结果。  
**追问：** 成本如何控制？  
**高级回答：** 限制子查询数、去重、并行召回并只在复杂问题启用。

## 26. Metadata Filtering 应在何时做？
**答案：** 尽量在召回前由检索系统强制执行。  
**追问：** 召回后过滤行不行？  
**高级回答：** 会降低有效 Top-K并有侧漏风险；项目按 project/institution/scope 先过滤。

## 27. 如何处理知识版本？
**答案：** 保留版本、有效期、状态和来源关系。  
**追问：** 相似的旧口径怎么办？  
**高级回答：** 默认过滤失效版本；若用于差异分析则显式标注，不能与现行口径同权。

## 28. 如何处理冲突证据？
**答案：** 按权威、时效、适用范围识别并暴露冲突。  
**追问：** 让 LLM 决定谁对吗？  
**高级回答：** 高风险冲突不能由模型擅自裁决，应创建带双方证据的人工问题。

## 29. Citation 应包含什么？
**答案：** 知识单元 ID、来源文件/版本、定位、引用片段和支持 claim。  
**追问：** 只列文件名够吗？  
**高级回答：** 不够，银行审核需要定位到 Sheet/Cell/Page/Line 并能回查。

## 30. Citation 验证分几层？
**答案：** 存在、可见、片段真实、支持 claim、版本适用。  
**追问：** 项目当前做到哪里？  
**高级回答：** 已验证 ID、启用和项目可见性；claim 支持和时效是深化点。

## 31. 什么是 Groundedness？
**答案：** 回答中的事实是否由给定证据支持。  
**追问：** 如何评？  
**高级回答：** claim-level 对齐，结合确定性规则、人工抽样和受控 judge；不能仅“有 citation=1”。

## 32. Faithfulness 与 Correctness 区别？
**答案：** Faithfulness 看是否忠于证据，Correctness 看是否符合真值。  
**追问：** 证据本身错误呢？  
**高级回答：** 回答可忠实但仍不正确，所以还需来源权威、版本和人工真值治理。

## 33. Recall@K 是什么？
**答案：** 期望相关证据有多少进入前 K。  
**追问：** 为什么 RAG 重视 Recall？  
**高级回答：** 正确证据未召回，生成层无从修复；先保证候选覆盖再精排。

## 34. Precision@K 是什么？
**答案：** 前 K 结果中相关证据的比例。  
**追问：** 与 Recall 如何权衡？  
**高级回答：** 初召回偏 Recall，进入模型的最终 Top-K偏 Precision，以免噪声挤占上下文。

## 35. MRR 是什么？
**答案：** 第一个相关结果排名倒数的平均值。  
**追问：** 适合什么问题？  
**高级回答：** 适合期望快速命中首个关键证据的问答，但多证据任务还要看 Recall/nDCG。

## 36. nDCG 是什么？
**答案：** 考虑多级相关性和排名位置的归一化指标。  
**追问：** 银行如何标相关性？  
**高级回答：** 可按直接支持、部分支持、背景相关、无关分级，并加入权威/适用性规则。

## 37. 如何构建黄金数据集？
**答案：** 从真实问题抽样，由业务/技术专家标答案、证据和无答案。  
**追问：** 只放成功题可以吗？  
**高级回答：** 不行；必须含冲突、过期、跨项目、无答案和精确字段类。

## 38. 如何评无答案问题？
**答案：** 看系统是否正确拒答并提出合理补证问题。  
**追问：** 指标？  
**高级回答：** no-answer precision/recall、拒答准确率和 open-question usefulness。

## 39. 如何区分检索失败与生成失败？
**答案：** 先检查正确证据是否在候选中，再看回答是否使用它。  
**追问：** 项目如何支持？  
**高级回答：** RetrievalLog 保存结果 ID，EvaluationResult 同时保存回答和 citation，可分层归因。

## 40. LLM-as-a-Judge 可以信吗？
**答案：** 可扩展但有偏差，不能当唯一裁判。  
**追问：** 怎么用？  
**高级回答：** 固定 rubric、盲化模型版本、与人工样本校准，安全硬规则仍用代码。

## 41. 如何控制 RAG Token？
**答案：** 去重、压缩、动态 Top-K、按 claim 选证据并限制引用长度。  
**追问：** 摘要会丢信息吗？  
**高级回答：** 会；保留原文引用和 ID，摘要只用于上下文，关键限定词不可丢。

## 42. RAG 缓存怎么设计？
**答案：** 缓存检索或答案，但 key 必须包含查询和配置版本。  
**追问：** 银行还要包含什么？  
**高级回答：** project/institution、权限、知识版本、Prompt/model，权限变化时必须失效。

## 43. 如何同步软删除到向量库？
**答案：** 事实库先标禁用，检索强过滤，并异步删除/重建索引。  
**追问：** 向量删除延迟怎么办？  
**高级回答：** 返回前仍回查 KnowledgeUnit 可见性，形成纵深校验。

## 44. 如何防 RAG 数据泄漏？
**答案：** 入库分级、检索前权限过滤、外发策略、输出过滤和审计。  
**追问：** 全局向量召回后过滤可行吗？  
**高级回答：** 不推荐，既影响 Top-K又有侧漏风险；应在向量检索层强制 metadata scope。

## 45. 如何防检索内容 Prompt Injection？
**答案：** 将文档视为不可信数据，隔离指令并限制工具。  
**追问：** 模型仍被诱导怎么办？  
**高级回答：** 即使决策受影响，Executor 的权限、Schema和工具白名单仍应阻断危险动作。

## 46. 表格 RAG 难在哪里？
**答案：** 行列关系、表头层级、单位、合并单元格和跨行限定。  
**追问：** 怎么切？  
**高级回答：** 保存表头路径与行键，按业务记录/字段切块，同时保留原 Cell 定位和表级摘要。

## 47. Graph RAG 何时有价值？
**答案：** 问题依赖实体关系和多跳路径时。  
**追问：** 一表通需要吗？  
**高级回答：** SQL/Shell 血缘天然是图，可作为结构化工具；不必把所有文档都先建知识图谱。

## 48. 为什么长上下文不等于更好 RAG？
**答案：** 更多证据可能带来噪声、冲突、成本和中间遗忘。  
**追问：** 怎么选 Top-K？  
**高级回答：** 按问题类型动态选择，并用 Recall、答案质量和延迟共同调优。

## 49. 项目 RAG 的三个亮点？
**答案：** 结构化范围过滤、混合检索、真实 citation 与无证据拒答。  
**追问：** 三个不足？  
**高级回答：** 关键词非完整 BM25、无 cross-encoder、claim-level citation/groundedness 尚粗。

## 50. 如何把 RAG 做到可上线？
**答案：** 数据治理、权限、混合检索、引用、评测、观测和发布流程缺一不可。  
**追问：** 最终验收看什么？  
**高级回答：** 质量分层指标、安全硬门禁、P95 延迟/成本、故障恢复和业务审核采用率，而非几条演示答案。
