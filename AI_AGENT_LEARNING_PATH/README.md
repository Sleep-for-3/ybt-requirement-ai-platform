# 银行一表通 AI 平台：企业级 AI / Agent 工程学习知识库

这套知识库的目标不是“把 AI 名词学一遍”，而是让你能完成并讲清一条真实企业链路：

```text
监管模板 / 历史口径 / 数据目录 / SQL-Shell 脚本
        ↓ 解析、标准化、权限过滤
混合检索（结构化条件 + 关键词 + 向量）
        ↓ 证据排序、引用定位
受控 LLM 生成（版本化 Prompt + 结构化输出）
        ↓ 证据校验、拒答、待确认问题
字段口径分析 Agent
        ↓ 人工审核、UAT、审计、评测、成本治理
可交付的一表通业务口径与技术溯源
```

## 使用顺序

1. 先读 [00-总学习地图](00-总学习地图.md)，明确能力树和成果物。
2. 按阶段读 01–07；每个阶段都要完成“源码定位”和“项目作业”。
3. 第 1 个月严格执行 [09-30天计划](09-30天计划.md)。
4. 每周从 [08-面试题库](08-面试题库/README.md) 抽题，口头回答并录音复盘。
5. 用 [10-能力评价与简历](10-能力评价与简历.md) 每两周自评一次。
6. 打开首课：`../lessons/0001-llm-call-chain.html`。

## 学习闭环

每个主题都用同一套五步法：

1. **说清楚**：两分钟内用业务语言解释。
2. **找得到**：在项目源码中定位入口、核心服务、模型和测试。
3. **改得动**：完成一个小改造，不停留在阅读。
4. **测得出**：定义成功指标、失败样本和回归测试。
5. **讲得像项目负责人**：用“问题—决策—权衡—证据—结果”表达。

## 成果仓建议

每周把成果保存到 `AI_AGENT_LEARNING_PATH/portfolio/`：

- `architecture/`：调用链、RAG、Agent、权限与部署图。
- `experiments/`：检索、Prompt、模型、延迟和成本对比。
- `tests/`：黄金问题集、失败案例、回归结果。
- `demo/`：演示脚本、截图、3 分钟和 10 分钟讲解稿。
- `interview/`：STAR 故事、题目错题和录音复盘。
