## 当前项目的真实边界

当前项目是“受治理的 RAG 业务平台 / Agent-ready 架构”，不是已经完成的自主 Agent 或多 Agent 系统。

已经具备：

- 多格式知识摄取、KnowledgeUnit、版本和作用域治理；
- 本地真实中文 Embedding、Milvus 持久化、版本化索引和原子激活；
- Keyword / Vector / Hybrid 检索、Citation 和 Grounded Answer；
- OpenAI-compatible Chat Gateway、Prompt 版本、结构化输出和模型调用日志；
- PostgreSQL、Redis、Celery、幂等、进度、重试和任务详情；
- 权限、数据分级、脱敏、审计、人工审核、UAT 和 RAG 评测。

尚未具备：

- 自主 Planner、动态 Tool Calling、Agent Loop；
- AgentRun / AgentStep 持久化和 Agent Memory 策略；
- 多 Agent 协作、MCP、可用的 Coze 工作流；
- 独立 Cross-Encoder Reranker、OCR、Token-aware Chunk；
- 大规模真实银行语料的生产容量与质量验收。

## 使用提醒

- 所有面试表达都要区分“项目已有”“本人实际完成”“原型”“规划”。
- 本机指标来自 10 份合成文档、100 个 Chunk、20 个问题，不能说成生产准确率。
- Mock 是测试替身，不代表真实模型或真实语义检索能力。
- Chat 模型与 Embedding 模型是两条独立链路：Embedding 找资料，Chat 写答案。
- 学 Agent 前先把 RAG、API、数据库、异步任务、权限和评测学扎实。
