企业 AI 工程术语速查

每个术语只记“是什么 + 一表通落点 + 一个误区”。

Token

模型处理和计费的文本片段。项目应记录 usage；误区：一个汉字必等于一个 Token。

Context Window

单次输入输出容量。项目用 Top-K证据控制；误区：长上下文等于可靠知识库。

Embedding

文本的稠密向量表示。项目用于语义召回；误区：能替代精确字段匹配。

Structured Output

符合JSON Schema的输出。项目应加Pydantic；误区：合法JSON等于业务正确。

Tool Calling

模型提出调用，应用执行。项目可封装目录/血缘工具；误区：模型直接拥有函数权限。

RAG

检索外部证据后生成。项目保留citation；误区：RAG就是向量库。

BM25

基于词项的稀疏检索。适合字段代码；误区：任意关键词加权都叫BM25。

Rerank

对候选做二阶段精排。项目当前是规则融合；误区：把融合分数叫cross-encoder。

Agent

围绕目标动态选工具并更新状态。字段取证可Agent化；误区：一次LLM调用就是Agent。

Workflow

预定义步骤和状态。审核/UAT适合；误区：所有流程都交给Agent更先进。

Groundedness

claim是否由证据支持。项目需claim-citation；误区：有引用就一定grounded。

HITL

关键节点人工审核。项目final_content必须人工采用；误区：HITL只是最后点确认。
