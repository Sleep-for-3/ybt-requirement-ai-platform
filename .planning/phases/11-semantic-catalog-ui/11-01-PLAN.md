## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser -> semantic catalog API | Query parameters and project identifiers are untrusted; authenticated project permission is required. |
| Catalog query service -> semantic/asset stores | Cross-model joins cross project, institution, lifecycle, and resource-permission boundaries. |
| API DTO -> browser render model | Readable bindings may reference assets the caller cannot inspect; redaction must happen before serialization. |
