## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| HTTP mapping id/date/principal to Project | Untrusted route/date inputs must resolve through the mapping row and existing technical.edit permission. |
| authorized Project/task to Context and prompt | Project/institution-scoped facts and confidentiality labels cross into the LLM boundary. |
| model/readiness result to mapping row | Concurrent, blocked, failed, or malicious output must not partially mutate governed content. |
| generation diagnostics to logs/audit | Traceability metadata is durable, but raw regulatory/knowledge/human/model content must not be stored in audit summaries. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-10-02-01 | Spoofing / Information disclosure | Principal and mapping Project handoff | high | mitigate | Pass frozen CurrentPrincipal intact, re-run PermissionService in the fresh transaction, reject disabled/revoked actors and falsey-id legacy spoofing, and test cross-project/institution ids never invoke or write from the model. |
| T-10-02-02 | Tampering / Information disclosure | bounded Context prompt | high | mitigate | Keep existing task prompt keys/schemas, quote Context data, aggregate selected confidentiality, and test restricted external denial with no draft write. |
| T-10-02-03 | Tampering | fallback and blocking path | high | mitigate | Delete legacy shared-query helpers/imports, propagate Context errors, return stable 409 readiness details, and assert no model/draft mutation on block. |
| T-10-02-04 | Tampering / Elevation of privilege | stale mapping result and governance | high | mitigate | Capture local snapshot without a lock; after model return validate actor and re-run PermissionService before fixed-order Project/task locking/comparison; reject stale output with no draft and test concurrent human edits plus adoption. |
| T-10-02-05 | Repudiation / Information disclosure | ModelCallLog and AuditLog | high | mitigate | Record only ids/counts/codes/date/readiness/hashes/output field names, link the sole retrieval log, and negative-test raw prompt/evidence/knowledge/draft/final content absence. |
