<threat_model>
ASVS Level: L1. Block on: high severity.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| authorized Project/task to ContextBuilder | Project and institution identity must be established once and handed to the canonical builder unchanged. |
| Context facts to adapter/prompt | Governed and potentially confidential text crosses into a bounded model input projection. |
| readiness/model result to task mutation | A block, interruption, or untrusted model field must not create a partial or authoritative write. |
| generation trace to AuditLog | Reviewable metadata crosses into durable audit storage and must exclude sensitive raw bodies. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-10-01-01 | Spoofing / Information disclosure | Principal, authorized Project and Context scope | high | mitigate | Pass the existing frozen Principal intact, reject falsey/missing/disabled queued users without legacy inference, require PermissionService-qualified Project, and test foreign project/institution ids fail before projection. |
| T-10-01-02 | Tampering / Information disclosure | adapter prompt projection | high | mitigate | Treat Context strings as quoted data, select explicit typed fields, aggregate every selected confidentiality level, apply deterministic bounds, and test restricted external denial before a model callback. |
| T-10-01-03 | Tampering | builder/readiness failure path | high | mitigate | Propagate construction failures, block authoritative core conflicts, expose stable diagnostics, invoke no fallback/model path, and assert task snapshots remain byte-for-byte unchanged. |
| T-10-01-04 | Tampering / Elevation of privilege | stale draft and physical/governance output | high | mitigate | Canonical task/Project snapshots enumerate every relevant field, no lock spans Context/model work, and downstream fresh actor validation/PermissionService then Project→task re-lock/compare precedes atomic apply. |
| T-10-01-05 | Repudiation / Information disclosure | generation audit trace | high | mitigate | Record ids, codes, counts, date source, readiness, and hashes through bounded redacted audit summaries; assert raw Context, prompts, evidence bodies, and generated content are absent. |
| T-10-01-06 | Denial of service | collectors and adapters | medium | mitigate | Batch connected metadata, sort before fixed caps, enforce zero adapter SQL, and retain fixed baseline-versus-growth query counts. |
</threat_model>
