# B2 跨层 Mapping 草稿核验与采用

日期：2026-09-30。范围：源到集市、集市到一表通两类当前映射。

## 页面与人工保护

`/mapping-drafts/{mappingType}/{mappingId}` 读取既有映射，分别展示 AI 候选、生成来源和人工最终内容。生成来源继续使用审计与模型日志交叉核验，并比较页面实际正文哈希。生成不写人工最终内容；采用需人工勾选确认，采用后仍为 draft，不自动审批。

当前工作台提供两类入口；固定历史需求不显示实时映射入口，字段编辑未保存时要求先保存。同页导航保留现有 sessionStorage 登录状态。

采用 API 显式校验 technical.edit，锁定映射并重新读取后检查：必须为 draft、人工最终内容为空、最近审核流程不在进行中。生成和采用都不能覆盖已有人工正文。此页不提供自由编辑表单；既有 PUT 编辑 API 的完整保护不在本改动的验收范围内。

## 页面快照校验

采用请求携带 `expected_draft_hash`（SHA-256、UTF-8、不归一化正文）。服务端在上述锁内比对当前候选。另一用户更新正文后，旧页面采用返回 409，不写最终内容。页面清除确认勾选，允许重新读取并核对。

这是采用接口的明确契约变化：旧调用方不能再以空对象成功采用。缺少请求体返回 409；不完整/非法对象返回 422。两类接口都使用同一严格请求 schema。校验正文一致性不等于重新验证候选的业务正确性，也不表示已完成审查。
