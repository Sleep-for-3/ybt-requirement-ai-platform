# B3 有界分句检索首版

日期：2026-09-29。状态：本地确定性实现及隔离测试通过；不代表完整 B3 或真实模型质量验收。

## 入口与边界

- `POST /projects/{project_id}/knowledge/planned-search` 要求真实用户和 `knowledge.search` 权限；字段、场景必须属于当前项目，授权在规划前完成。
- 查询最多 2000 字符，结果上限 1～50；请求拒绝额外字段。首版固定 keyword_only、当前生效资料，客户端不能切换向量或历史范围。
- 保留完整问题作为第一轮。只按分号、问号、换行分句，最多再检索三个不同分句。超过三句或出现引号时只用完整问题，并返回明确说明；不截断、不推断省略的实体、不改写项目/字段/场景过滤器。
- 每轮复用已有领域词扩展和生效/范围筛选，最多四次检索，每轮至多 top_k 条证据。没有语言模型、Embedding、外部向量服务、源库查询或工具执行。

## 合并及一致性

- 仅合并检索返回的真实知识单元；按单元 ID 去重。同一轮重复单元不重复计分。
- 保留既有资料权威等级优先级，等级内使用 reciprocal-rank fusion：各轮 `1 / (60 + rank)` 求和；同分按单元 ID。分数只是排序依据，不能解释为业务正确率。
- 保留原引用、文档版本、内容哈希、内容和出处，增加命中轮次/名次。跨轮同一单元内容或版本不一致则 409。
- 返回前重新加载授权和生效资料，核对项目/场景/类型、文档关联、内容和版本。失效/变化则拒绝返回，并由请求事务回滚日志。
- 所有子轮日志与汇总日志在同一事务内提交。汇总日志记录算法版本、完整计划、子日志 ID、过滤器和真实用户；没有伪造模型调用日志。

## 页面

知识检索页可选“分句检索（本地规则，最多四轮）”，展示实际计划、预算回退说明、来源引用和各轮命中位置。项目/查询/模式改变清除旧结果；请求失败不保留旧证据；空结果不生成回答。
