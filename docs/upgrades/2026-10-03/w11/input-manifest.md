# W11 输入 manifest（模板，由银行/UAT 负责人填写）

填写规则：每份输入都要有**文件名 + 版本/日期 + SHA-256**，与 UAT 轮次绑定的 `content_version` 对应。
不得用"最新版""现行版"这类无版本描述；拿不到 hash 的输入必须标注原因。

| # | 类别 | 名称 | 版本/日期 | SHA-256 | 用途 | 备注 |
| --- | --- | --- | --- | --- | --- | --- |
| 1 | 监管目标模板 | 一表通目标表（Excel） |  |  | 目标字段与口径 | 列名须与平台导入模板一致 |
| 2 | 监管目标模板 | 监管报送目标表 |  |  | 报送口径 |  |
| 3 | 来源系统 | 来源表 1（表名/系统） |  |  | 关联/聚合来源 | 只读账号 |
| 4 | 来源系统 | 来源表 2（表名/系统） |  |  | 多来源优先级 | 只读账号 |
| 5 | 来源系统 | 集市表（表名） |  |  | 加工中间层 |  |
| 6 | 目录/元数据 | 目录同步快照 |  |  | 字段检索与推荐 |  |
| 7 | 制度/知识 | 制度文件（docx/pdf） |  |  | 口径依据与 citation | 版本须与现行一致 |
| 8 | 制度/知识 | 历史口径说明 |  |  | 历史口径对照 |  |
| 9 | 脚本 | 上游加工脚本 |  |  | 血缘与变更影响 |  |
| 10 | 配置 | 平台配置摘要（脱敏） |  |  | 可复现性 | 不含密钥 |

## 覆盖自检（对应 W11 起点要求）

- [ ] ≥ 8 个目标字段
- [ ] ≥ 2 个来源表
- [ ] 1 个集市表
- [ ] 1 个监管目标表
- [ ] 覆盖：多表关联 / 聚合 / 过滤日期 / 码值 / 空值 / 多来源优先级 / 手工补录
