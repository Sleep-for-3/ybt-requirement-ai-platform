## 阶段实施规划

### 第一执行阶梯 (P0 - 立即自主实施与验证)
1. **实施项 1：RAG 银行领域检索增强（Domain-Aware Hybrid Retrieval）**
   - 引入银行监管业务专有同义词映射与专业词典（ECIF/客户、信贷/借据/合同、存款/结息、住房按揭/房贷等）；
   - 在 `keyword_index.py` 中引入加权词扩展，提升召回率（Recall@K）；
   - 验证：编写测试验证同义词在无向量库环境下的召回率从 0% 提升至 100%。

2. **实施项 2：需求生成 Agent 自我反思纠错循环（Self-Correction Loop）**
   - 在 `requirement_generation_worker.py` 中重构生成执行流；
   - 接入“执行 -> 严格校验 -> 错误诊断生成 Feedback -> 带着上下文与错误反馈再次反思修正 -> 二次校验”的闭环；
   - 避免非致命幻觉直接进入 `blocked`，显著提升生成通过率与需求可用度。

3. **实施项 3：智能 Schema Linking 意图解析器（Smart Intent Parser）**
   - 重构 `natural_language_task_parser.py`；
   - 支持从项目当前已注册的数据源与元数据目录中自动进行候选表名/字段名模糊关联，摆脱死板数据源名称硬编码。
