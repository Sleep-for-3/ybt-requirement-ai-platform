## 历史设计与实施记录

`docs/superpowers/specs/` 保存早期设计规格，`docs/superpowers/plans/` 保存对应实施计划。这些文件用于追溯历史决策，不作为当前启动或部署操作手册，因此保留原始文件名。

## Windows 本地启停脚本

统一脚本位于 [`scripts/项目启停.ps1`](../scripts/项目启停.ps1)：

直接右键脚本选择“使用 PowerShell 运行”会进入常驻菜单，显示项目总体状态、各服务 PID、访问地址、健康检查和日志目录，并可执行启动、刷新、重启和停止。退出菜单只关闭控制台，不会停止服务。

```powershell
.\scripts\项目启停.ps1 start
.\scripts\项目启停.ps1 status
.\scripts\项目启停.ps1 restart
.\scripts\项目启停.ps1 stop
```

脚本自动执行数据库迁移，启动 PostgreSQL、Redis、Celery、Milvus、FastEmbed、前后端，检查真实向量自检和健康状态，并把进程状态、模型缓存和日志写入已被 Git 忽略的 `.local-run/`。
