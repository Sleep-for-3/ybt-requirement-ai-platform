**同一批失败暴露的四个缺陷（均已在 R6 第 1 节修复并回归）**：

1. **可诊断性**（D7）：失败调用只落 `error_type=provider_error`，HTTP 状态码与响应片段全部丢失。补上 `http_status` / `error_detail` 后，真实失败一次看清：`400 model_not_found`、`403 insufficient_quota`、`524 A timeout occurred`。
2. **json 模式提示词**（D8）：网关要求 `response_format=json_object` 时消息里必须出现 "json"，`regulatory_field_explanation` 的提示词没有该词，于是被 400 直接拒绝——这正是"678–1076 ms 快速失败"的根因。修复后该链路稳定成功（latency 11–36 s）。
3. **瞬时故障无兜底**（D9）：提供方（网关）在真实负载下会返回 `model_not_found` / `403 配额` / `524`。新增兜底模型链与有界重试；实测有 1 次请求由兜底模型 `gpt-6-astra` 回答成功。
4. **超时过短**（D10）：模型往返超时硬编码 60 s，而真实响应 11–123 s。改为 `LLM_TIMEOUT_SECONDS`（1–180，默认 60），Smoke 客户端超时改为 `SMOKE_REQUEST_TIMEOUT_SECONDS`。
5. **交互式调用无预算、无降级、无诊断**（D11）：`/knowledge/ask` 在提供方超时/故障时直接 500（引用与检索结果一起丢），`/ai-runtime/test-chat` 只回 `503 provider_error`，且不落 `model_call_logs`。新增 `LLM_INTERACTIVE_TIMEOUT_SECONDS`（默认 90、单次重试）、问答降级为「证据 + `answer_status=degraded` + 结论待确认」、连接测试 503 附带脱敏后的 `provider/model/http_status/provider_detail`，并写结构化日志 `model_call_failed`（含 `request_id`）。
6. **会话中途过期无续期**（D12）：访问令牌 15 分钟、前端无自动续期，真实模型链路必然超过该寿命，用户被清会话并跳登录页；PG16.4 + 真实模型 Smoke 也在 `adopt-ai-draft` 处以 `401` 中断。修复为「401 → 静默续期 → 重放一次」，并在演练脚本内同步实现与验证。
7. **规模基线从未在真实数据库上成立**（D13）：基线脚本只能跑 SQLite，且 fixture 外键悬空（SQLite 默认不校验外键）。修复为可指向真实 PostgreSQL（非空库拒绝）+ 补齐 fixture 依赖链，已在 PG16.4 上跑出 SMALL/FULL 规模。
8. **单次生成最坏等待无上界 + 前端统一 60 s 超时**（D14）：真实网关抖动时一次 `mart_to_ybt_mapping` 成功调用耗时 **411.6 s**（`120 s × 3 次尝试 × 2 个模型` 的最坏预算约 12 分钟），而前端 60 s 就报"请求超时"，用户重试还会产生重复草稿。修复为按路径区分请求预算（默认 60 s / 长耗时 600 s）；根治走 R6 P1-6。

**环境阻塞（非产品缺陷，登记为 R6 P2-4/P2-6）**：本机 WSL 发行版在演练期间反复整体重启（观测到 8 分钟内重启一次、后期 1–2 分钟一次），`docker exec` 启动的 API/Celery/Smoke 进程与容器一同被终止，真实 PG + 真实模型的组合因此在容器内无法跑完。**本轮已给出并验证了规避方案**：应用栈改到 Windows 原生运行（`TASK_QUEUE_PROVIDER=inline`），数据库改用本机独立真实 PostgreSQL 实例（scoop 18.4，`127.0.0.1:15433`，数据目录 `backend/.smoke-run/pgdata`），随后同一套 Smoke 在 501 s 内跑完并通过（见上表）。

结论：**真实模型经应用接口的全流程业务链路已通过**——两条环境各自 `SMOKE_EXIT=0`（Windows 原生栈 + SQLite；Windows 原生栈 + **真实 PostgreSQL 18.4**，501 s、23 次调用 0 失败）。生产基线是 PostgreSQL 16，故仍须按 P0-6 在脱敏生产副本上复核迁移与结构指纹；此外容量/规模类结论仍未验证。
