### 4.2 这些是"我自己的判断错"，写下来避免重犯

1. **"T_1_3 有 248 个字段、脚本只覆盖 29 个"是错的**：真实 `TargetField` 是 90 表 2 422 字段、单表 5–88 字段，`T_1_3` 只有 30 个。覆盖缺口真实值 6 个（21 条需求 237 字段中），不是 219 个。
2. **"同快照导出两次同字节" ≠ "渲染可复现"**：冻结导出复用产物（同一 `render_identity` 不重渲），真正的复现性要靠重放比对（round 71 才做）。
3. **弱断言放过缺陷**：我用 `includes("T_8_1")` 校验筛选，把 `T_8_10` 也被带进来的问题漏掉了。断言要写到"数量与行内容同时成立"。
4. **重启 / 清 `.next` 不是万能药**：一次"点了没反应"排查中我先后怀疑编译缓存、事件绑定，最后才是重挂载；顺序应该是"请求发没发 → 状态设没设 → 渲染树是否被换掉"。

### 4.3 环境与工具坑（会浪费半天的那种）

- WSL 空闲即关容器（Milvus 全灭）；`docker start` 顺序 etcd/minio → milvus。
- `next dev` 长时间运行后路由 chunk 会 404（`/_next/static/chunks/app/projects/%5BprojectId%5D/...`），页面永远"加载中"；修法是删 `.next` + 带 `NEXT_PUBLIC_API_BASE_URL` 重启。
- dev server 启动后 `NEXT_PUBLIC_*` 不再变；改了 `.env` 必须重启。
- Playwright：`waitForFunction` 不能吃 JS 函数参数（改成 node 侧轮询）；点击前必须等页面安定（重挂载会把筛选状态重置，`Element is not attached to the DOM`）。
- PowerShell：循环变量不能叫 `$pid`（只读自动变量）；反引号拼 `\r\n` 易变字面量；`alembic` 走 stderr 会显示 exit 1 但实际成功。
- 仓库文件换行混杂：`frontend/app/**/page.tsx`、`lib/*.ts`、服务层多为 **CRLF**，Python 补丁必须 `open(newline="")` 读、`\n` 归一化匹配、写回 `\r\n`，否则 `replace` 静默不生效。
- 本仓库没有 `app.models.base`、没有 `guard_project_resource`；鉴权用 `PermissionService(...).require_project_permission(pid, "project.view")`，测试夹具是 `snapshot_api`（返回元组）+ `_export(client, project, requirement)`。
- `RequirementRenderArtifact.template_sha256` / `media_type` 是 NOT NULL，测试造数据要给 `""` 而不是 `None`。
