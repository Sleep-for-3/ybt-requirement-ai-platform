## 继续所需的最小来源包

由用户或实际来源所有者提供一个此前未用于本项目上传、索引、检索、演示或评测的独立资料包，并在包内附一份简短来源说明，包含：

1. 来源所有者/业务联系人、取得渠道、资料形成或生效日期、文档版本/家族，以及允许用途（本地审核、隔离索引、真实模型出机评测分别说明）。
2. 一句可追溯的历史使用声明：该包及同家族材料此前是否进入本平台项目、`dev_storage_local`、演示、历史评测或外部测试；若进入，给出项目/版本/日期或将该家族按已观察处理。代理可以核对证据，但不能凭空证明业务系统之外的历史。
3. 建议至少 30 个可从原文形成的问题，覆盖至少 3 个相互独立的文档家族及 2 种业务问题类型；每题可定位到原文页/段/行/单元格，答案依据、适用版本、可答/部分支持/待确认/拒答边界可审核。题目少于该建议规模时先作为小样本探索，不作稳定发布门禁。
4. 如果材料含个人、账户、机构保密或其他受限信息，先提供已授权脱敏版本。没有明确允许模型出机评测时，只做本地原文审核和隔离组件检索，不向模型或测试服务器发送。

收到后由代理逐题审核，不要求用户逐题操作；按文档家族先划分调参/留出、再封存留出预期。冻结来源包、问题、gold、代码、语料、索引、模型、Prompt 和配置身份后，才可按共享预算进行首次真实模型调用。第一次运行即把留出改为已观察；后续调参另用新来源。
