Date: 2026-11-17

## Finding and change

- Static call-path review found that chat completions reserved/settled each actual provider attempt through the shared SQLite budget, while `OpenAICompatibleEmbeddingService` used a separate HTTP path and did not.
- External/non-local embedding requests now use the same budget ledger. Each batch request and each retry reserves before dispatch and settles from provider usage; absent or invalid usage conservatively charges the reservation.
- `local_*` and Mock embedding services do not consume the external provider budget. A configured `RAG_MODEL_BUDGET_REQUIRED=true` with missing paths fails before an external embedding HTTP request.
- Added tests for external batching/retries, missing required budget, cap exhaustion before a retry dispatch, and local-provider exclusion.
