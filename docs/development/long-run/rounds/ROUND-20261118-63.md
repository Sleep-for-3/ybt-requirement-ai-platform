# Round 63：问答期间资料变化的 HTTP 契约

日期：2026-11-18

知识问答在引用资料撤回、禁用、权限或正文发生变化时返回 HTTP 409，提示“回答期间引用资料状态发生变化，本次回答未返回。请重新提问。”；普通参数校验错误仍返回 400。原有服务层引用复核继续拒绝返回失效资料对应的答案。

## 实现

- `CitationEvidenceChangedError` 继承 ValueError；只在开启治理复核且引用编号全部属于请求正文快照时用于失效和变化检测。缺少编号、未知编号、无快照的传统校验继续使用普通 ValueError。
- 问答路由单独捕获该异常并返回固定409提示，不向页面暴露知识单元编号或内部诊断。一般 ValueError 保持400。
- 知识问答页面复用的 `askErrorMessage` 为409提供固定提示。
- 覆盖生成与judge两个阶段；judge关闭、正常和失败；撤回、禁用、归档、正文、内容标识、项目范围、单元范围、密级和版本钉扎变化，以及无变化和非法输入对照。
