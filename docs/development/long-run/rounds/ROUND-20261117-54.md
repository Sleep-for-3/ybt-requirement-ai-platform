# Round 54：知识问答规划必需步骤校验

日期：2026-11-17
目标：修复知识问答规划可省略回答步骤、却以成功完成状态结束的问题。
结果：缺失回答步骤及仅有可选回答步骤的计划现在会被拒绝；不合格规划沿现有有界修复路径失败后保留确定性知识问答计划。

## 发现

Round53 attempt7 只读采集的任务详情显示：任务 `completed`、summary 无回答、仅 1 个已完成步骤 `s1`，无引用。代码追踪确认该步骤来自 Mock planner 的 `summarize_evidence` 通用计划。原知识问答校验只检查“若存在回答步骤，其硬依赖不能经过可选历史案例”，却不检查回答步骤是否存在/必需。因此 schema-valid 计划可以绕开确定性计划中的 `answer_knowledge_question` 步骤。

该行为不是“待确认回答仍允许流程完成”的状态契约问题，而是知识问答规划漏掉必须回答的工具步骤。

## 修改

- `backend/app/services/agent/planner.py`：知识问答计划必须至少包含一个 `required=true` 的 `answer_knowledge_question` 步骤；缺失或仅可选时生成可修复校验错误。
- `backend/tests/test_agent_optional_dependency_contract.py`：覆盖无回答、可选回答、Mock filler 计划被拒绝、一次有界修复后返回无效时降级。
- `backend/tests/test_agent_knowledge_question.py`：覆盖 deferred LLM 计划被拒绝后仍保留确定性计划中的必需回答步骤。
