## 失败与处置

- Python 子进程调用 `wsl.exe` 时遭遇 `Wsl/E_ACCESSDENIED`；交互式 PowerShell 的 WSL 命令正常。调整职责边界：Docker 依赖容器由显式 WSL shell 脚本创建，Python 仅管理本地 API/worker。未通过 Python 绕过限制。
- `%LOCALAPPDATA%` 下预定新目录受系统 ACL 拒绝，创建秘密文件前失败。切换到已确认 git-ignore 的项目 `.local-run` 私密区后再生成本轮新凭据；未写入工作区普通文档。
- API/worker启动后的首次 `start` 命令在写报告时触发 `NameError`。当时 API 和 worker 已运行且迁移已完成，因此没有重跑 `start`。新增 `finalize` 只读子命令核实现存 API、版本、健康和空 Milvus后成功写入首次运行报告。该失败保留在会话/日志中，代码已补齐变量引用。
- API readiness 首次探测短超时失败；再次以20秒有界超时实测返回 `ready`。启动日志和第一次探测失败均保留。
