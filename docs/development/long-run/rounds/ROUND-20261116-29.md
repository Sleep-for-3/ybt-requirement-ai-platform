## 初始诊断结论与未决

- 已观察 SQL 题只能作为 tuning/regression，不能重命名为 holdout；P0-A 仍需来自完全未观测来源的新独立留出。
- SQL 检索召回、跨问题角色覆盖和短上下文窗口均是实测问题。需要先分离“候选池未召回”与“候选已召回但装配遗漏”，再在已观察题上构造可复现反例与防误伤测试。
